# 三版任务目标与验收标准

记录日期：2026-10-19。场景：家庭看宠物，人在外面可用手机查看。已有 ESP32-CAM、常开 Ubuntu 22.04 笔记本和独立照明。

状态区分：**源码已写**不等于**已构建**，已构建不等于已烧录、已部署或已通过真实外网验证。当前只有第一版源码与文档，下面所有实物验收均待执行。

## 第一版：远程实时查看与拍照

目标：手机使用移动数据，在授权的私有网络内打开网页，查看宠物当前画面并保存照片。

| 任务 | 交付内容 | 当前状态 |
| --- | --- | --- |
| ESP32-CAM 独立运行 | 独立电源、2.4 GHz Wi-Fi、JPEG 接口 | 源码与接线说明已写；硬件待确认 |
| 初始画面 | 默认 640×480，三档分辨率 | 源码已写，画质及帧率待实测 |
| Ubuntu 网关 | 单采集线程、按需采集、共享 MJPEG | 源码已写，待运行 |
| 手机网页 | 登录、观看／暂停、拍照下载、全屏 | 源码已写，待手机浏览器验证 |
| 外网访问 | Ubuntu 与手机安装 Tailscale，Serve 私有入口 | 操作步骤已写，待用户登录配置 |
| 连接恢复 | Wi-Fi 重连、采集重试、过期画面提示 | 源码已写，待断网测试 |
| 基本访问保护 | 摄像头密钥、网页密码、CSRF、私有入口 | 源码已写，待验收 |
| 长期开机 | systemd 模板、日志、挂起说明 | 模板已写，待 Ubuntu 部署 |

第一版验收：

- 摄像头断开 USB 串口后，独立供电仍能通过 Wi-Fi 工作。
- Ubuntu 能访问摄像头；浏览器实际看见实时画面，不使用演示图片冒充在线。
- 手机关闭 Wi-Fi、使用移动数据，开启 Tailscale 后可以登录并观看。
- 拍照下载的 JPEG 可打开；调整画质后真实图片尺寸相应改变。
- 摄像头掉电或 Wi-Fi 中断时显示异常；恢复后可以自动续看。
- 暂停、切换后台、关闭页面后，采集请求会停止（允许在途请求结束）。
- 未登录者不能读取画面；密钥错误时有明确提示。
- 至少一次重启 Ubuntu 后确认服务恢复；建议进行 8 小时以上稳定性观察，记录而非预设帧率、延迟和温升。

第一版不包含连续录像、声音、对讲、事件通知或 AI 识别。普通 ESP32-CAM / OV2640 不能因有视频画面就推定具备收音能力。

## 第二版：事件检测、留图与通知

目标：不一直盯着手机，也能知道宠物活动事件，并查看对应图片。

| 任务 | 计划内容 |
| --- | --- |
| 检测服务 | 在 Ubuntu 上做画面变化检测，设置区域、阈值、时段和冷却时间 |
| 事件留存 | 记录时间、事件图片和处理状态，设置保存天数与磁盘上限 |
| 通知渠道 | 先选定一种通知方式，再实现接收端、频率限制和失败重试 |
| 事件页面 | 按时间查看事件和下载图片 |
| 运行状态 | 摄像头离线提醒、恢复提醒，避免重复发送 |
| 误报调节 | 针对灯光变化、窗帘等误报提供调整方式 |

依赖：第一版稳定运行，确定通知平台及保存策略。第二版检测需要 Ubuntu 在无人观看时也采集；这是相对第一版“按观看需求采集”的明确架构变化。

第二版验收：真实运动可产生事件；连续活动不会无限通知；无活动与照明变化进行对照观察；磁盘到达阈值时按策略清理；网络恢复后重试行为可追踪。通知发送只在用户完成渠道配置并授权启用后进行。

## 第三版：历史回放、多用户与智能识别

目标：形成可长期使用的家庭监控系统，能回看事件并减少无关通知。

| 任务 | 计划内容 |
| --- | --- |
| 录像与回放 | 优先事件短片，再评估连续录像；Ubuntu 负责转码、索引和播放 |
| 存储管理 | 配额、自动清理、可选 NAS、备份与隐私删除 |
| 人形／宠物识别 | 在 Ubuntu 上选型模型，区分人、宠物与背景变化，评估 CPU/GPU 负载 |
| 多用户 | 独立账号、权限、访问撤销与会话管理 |
| 使用体验 | 手机安装式网页、事件检索，按需求评估多摄像头 |
| 长期维护 | 配置备份、升级和回退、运行指标 |

依赖：确定 Ubuntu 性能和磁盘容量，测量视频源质量及带宽。识别任务交给 Ubuntu；若 ESP32-CAM 的画质、帧率或编码能力不足，再决定是否更换摄像头。

第三版验收：历史视频能定位并播放；配额清理可预测；不同用户权限生效且可撤销；识别用实际家庭画面评估误报与漏报；重启后索引和配置恢复。识别不作为宠物安全或医疗保障。

## 推进顺序

先构建并完成第一版实物验收，再确定第二版的通知渠道与存储期限；第二版可靠后再扩展录像和识别。后两版目前为规划，尚无实现。
