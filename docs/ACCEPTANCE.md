## Wi-Fi 配网与恢复（新固件实机待验收）

- [ ] 新设备不含编译期 Wi-Fi 凭据，首次自动开启独立密码的热点；串口 `wifi-info` 可查看密码，普通日志不输出目标 Wi-Fi 密码。
- [ ] 手机访问 `http://192.168.4.1:8081`，无互联网提示后仍可提交；隐藏 SSID／中文 SSID、错误密码和开放网络按预期处理。
- [ ] 手机窄屏无横向溢出；SSID 可输入、筛选和下拉选择，列表按信号由强到弱，同名去重，刷新／失败提示正常；扫描期间不阻塞取消和试连，特殊字符网络名只显示为文本。
- [ ] 正确配置取得 IP 并保存，热点关闭；断电重启自动连接，mDNS 和网关采集恢复。
- [ ] 试连错误、取消、10 分钟到期均保留旧网络；失败重试不会覆盖当前 NVS 配置。
- [ ] 局域网接口不可访问配网表单；无令牌／错误令牌的修改操作被拒绝；`POST /network/setup` 缺少或错误摄像头密钥被拒绝。
- [ ] 路由器临时断电时不自动开放热点，恢复后可重连；配网窗口内旧网络掉线也能重试。
- [ ] 串口 `wifi-setup`／`wifi-cancel` 可离线恢复；仅完整 `wifi-forget CONFIRM` 清除网络，不清除摄像头密钥和热点密码。
- [ ] 手机热点下验证 Ubuntu 到摄像头 HTTP 和 mDNS 可达性；记录 AP+STA 信道变化时手机断连与恢复行为。
- [ ] 受控掉电测试验证双槽保存后能够恢复有效配置；自动化 mock 不替代真实 Flash 掉电测试。

## 画面和手机操作

- [ ] 默认画面为 VGA；三档切换后下载的 JPEG 实际尺寸分别正确。
- [ ] 画质控制失败时不会在界面上假报成功。
- [ ] 网页补灯按钮可点亮／关闭 GPIO4 LED；未登录、无 CSRF 或无摄像头密钥时不可控制。
- [ ] 补灯点亮约 1 分钟后自动关闭，刷新页面和板端重启后按钮反映实际状态；断网时最终自动关闭。
- [ ] 拍照保存的是新获取图片，手机可通过下载链接保存并打开；右上角有清晰的 `YYYY-MM-DD HH:MM:SS` 北京时间水印，且与抓拍时刻一致。
- [ ] 实时画面右上角显示最新收到帧的年月日时分秒；新帧到达才更新时间，断流、卡帧或暂停时不出现仍在走秒的假实时钟。
- [ ] 两个浏览器观看同一路画面，不出现两个独立摄像头采集线程。
- [ ] 达到观看连接限制时能恢复，不把摄像头长期卡死。
- [ ] 暂停／页面后台／关闭页面后，不再由该页面维持采集；允许在途请求超时后释放。
- [ ] 摄像头离线时不把最后一帧当作实时画面持续展示。
- [ ] 摄像头掉电再上电、Wi-Fi 断开再恢复后，页面可以重新显示画面。
- [ ] 在受控维护窗口让路由器给摄像头分配不同 IP（避免占用其他设备地址），确认串口和 `getent` 均反映新地址；不修改 `CAMERA_URL`、不重启网关，页面自动恢复新帧，拍照、分辨率和补灯控制仍可用。记录缓存更新及恢复耗时。
- [ ] 浏览器不支持全屏时有提示，竖屏布局可操作。
- [ ] 手机上实际验证后台切换、返回页面、登录到期后的重连行为。

## 第二阶段 2A：移动检测与事件留图

- [ ] 无浏览器观看时，网关仍以约 2 FPS 后台采集；有人观看时没有出现第二个独立采集线程。
- [ ] 在检测区域内做真实移动，连续 2/3 帧命中后生成一个事件。
- [ ] 单次连续活动只形成一个事件；停止活动约 15 秒后事件结束。
- [ ] 每个移动事件都有触发前、首次触发、变化峰值三张可打开 JPEG；三张图右上角都带各自实际抓帧时刻的 `YYYY-MM-DD HH:MM:SS` 北京时间水印。
- [ ] 峰值图确实对应本事件变化比例较高的时刻，不是固定复制首帧。
- [ ] 在 ROI 外活动不触发；在 ROI 内相同活动可以触发。
- [ ] 开关房间照明进行对照，不应把近似全画面均匀亮度变化持续报成移动。
- [ ] 网页拖画 ROI 后保存，刷新页面坐标仍保留；切换摄像头分辨率后区域比例不漂移。
- [ ] 提高像素／面积阈值后灵敏度下降，降低后灵敏度上升；非法范围被接口拒绝。
- [ ] 事件页“全部／今天／最近 7 天／未查看”筛选、标记已查看、三图查看和删除均正常。
- [ ] 未登录不能读取事件图片；修改设置、标记和删除缺少 CSRF 时被拒绝。
- [ ] 删除事件后 SQLite 记录和对应图片目录都消失，其他事件不受影响。
- [ ] 点击“清空全部事件”必须先看到不可撤销确认；取消不发请求，确认后全部事件记录和图片消失，但 ROI 与阈值设置保留。
- [ ] 直接调用清空接口但缺少 CSRF 或未提供布尔值 `confirm: true` 时被拒绝，不删除任何事件。
- [ ] 用缩短保存天数或测试配额验证：清理按最旧完整事件执行，不产生孤儿图片或记录。
- [ ] 摄像头持续离线约 30 秒只记录一次离线；恢复首帧只记录一次恢复。
- [ ] 服务重启后 SQLite、检测设置和历史事件仍存在；不会启动重复检测线程。
- [ ] 连续观察 2～3 天，记录每天事件数、误报类型、漏报场景、CPU、磁盘增长和摄像头温升，再冻结正式阈值。
